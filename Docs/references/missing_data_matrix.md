## 우선순위별 요청 범위

- P1: 2009·2010년 경기 수(기록 행)가 절반 분량(6,356 / 5,466) → 기록 행 자체가 절반.
- P2: 2001~2019, 2021~2025년의 홈런(HR), 2루타(2B), 3루타(3B), 도루(SB) 비어 있음.
- P3: 2001~2019, 2024년의 볼넷(BB), 삼진(SO), 몸에 맞는 공(HBP) 비어 있음.
- P4: 1989~2000년의 득점(R) 비어 있음.
- P5: 순위표 자격 기준이 1982~2000년은 30타석·90아웃이라 사실상 없음. 크롤러 로직 수정 요청.

## C. 완료 판정 기준

1. 컬럼 합계가 의심 기준을 넘는지: P2/P3/P4 해당 시즌·컬럼 합계가 0 또는 안타 대비 0.5% 미만이면 의심.
2. 2009·2010년 경기 수가 정상 규모로 돌아오는지: game_batting_stats 행 수가 5,000+ 회복.
3. 순위표 1위의 타석이 극단값이 아닌지: `_compute_min_pa`의 floor(30)이 1982~2000 시즌에 적용되지 않도록 크롤러/계산 로직 수정 필요.
