# 결측 범위 운영자 인계 메시지

## 산출물

- 시즌×컬럼 결측 매트릭스: `Docs/references/missing_data_matrix.md` (및 `.json`)
- 근거 쿼리: `Docs/references/missing_data_queries.sql`

## 판정 기준

판정은 안타 대비 비율 기준의 휴리스틱이라 "의심 목록"입니다. 컬럼 합계가 의심 기준을 넘는지, 2009·2010년 경기 수가 정상 규모로 돌아오는지, 순위표 1위의 타석이 극단값이 아닌지 확인합니다.

## 우선순위별 요청 범위

- P1: 2009·2010년은 경기 수 합계가 절반 분량(6,356 / 5,466)이라 기록 행 자체가 절반입니다.
- P2: 2001~2019, 2021~2025년의 홈런, 2루타, 3루타, 도루가 비어 있습니다.
- P3: 2001~2019, 2024년의 볼넷, 삼진, 몸에 맞는 공이 비어 있습니다.
- P4: 1989~2000년의 득점이 비어 있습니다.
- P5: 순위표 자격 기준이 1982~2000년은 30타석·90아웃이라 사실상 없습니다. 크롤러 로직 수정 요청입니다.

## 에이전트 제약 사항 (중요)

이 저장소 에이전트는 외부 크롤링이나 추정으로 데이터를 채울 수 없습니다. 운영자 제공 데이터 절차(`import_manual_baseball_data.py`)를 따릅니다. 데이터 보정은 해당 절차를 통해서만 수행해 주시기 바랍니다.

## 완료 판정 기준

1. 컬럼 합계가 의심 기준을 넘는지 (P2/P3/P4 대상 시즌·컬럼).
2. 2009·2010년 경기 수가 정상 규모로 돌아오는지.
3. 순위표 1위의 타석이 극단값이 아닌지 (P5 크롤러 로직 수정 후).
